# مدیریار (Modiryar) - اپلیکیشن جامع مدیریت کارهای روزانه
# Daily Management & Productivity Planner

سامانه هوشمند و یکپارچه برنامه‌ریزی روزانه، مدیریت وظایف (To-Do List)، رهگیری عادات (Habit Tracker)، تایمر تمرکز پومودورو (Pomodoro)، برنامه زمانی (Time Blocking) و آمار عملکرد.

---

## 🚀 راهنمای نصب و اجرای محلی (Quick Start)

### پیش‌نیازها
- نصب [Node.js](https://nodejs.org) (نسخه 18 یا بالاتر)
- مدیریت بسته‌های `npm` یا `bun` یا `pnpm`

### ۱. نصب وابستگی‌ها
```bash
npm install
```

### ۲. اجرای سرور توسعه (Development Server)
```bash
npm run dev
```
سپس مرورگر خود را باز کرده و به آدرس `http://localhost:3000` یا آدرس نمایش داده شده در ترمینال بروید.

### ۳. ساخت نسخه نهایی (Production Build)
```bash
npm run build
npm run preview
```

## ✨ امکانات اصلی (Features)

1. **نمای کلی و برنامه‌ریزی روز (Daily Overview)**:
   - تاریخ شمسی خودکار و زنده (گاه‌شماری جلالی/شمسی بدون وابستگی سنگین).
   - اولویت‌های طلایی سه‌گانه روز (قانون تمرکز بالا).
   - ردیاب هیدراتاسیون (۸ لیوان آب روزانه با قابلیت افزایش/کاهش).
   - ثبت حس و حال روزانه (Mood Tracker).
   - دفترچه شکرگزاری و بازتاب پایان روز.

2. **مدیریت پیشرفته وظایف (Task Manager)**:
   - سطوح اولویت‌بندی سه‌گانه (**Low / Medium / High**).
   - مرتب‌سازی هوشمند بر اساس میزان اهمیت کارها یا تاریخ موعد.
   - زیروظایف و چک‌لیست تعاملی با نوار پیشرفت.
   - تخمین زمان انجام کارها به دقیقه.
   - جستجوی سریع و فیلترهای چندگانه.

3. **سیستم دسته‌بندی و برچسب‌های سفارشی (Categories & Tags)**:
   - مدیریت دسته‌بندی‌ها (کاری، شخصی، سلامت، یادگیری، مالی و دسته‌های دلخواه شما).
   - پالت رنگی استاندارد برای هر دسته.
   - برچسب‌های سفارشی (Custom Tags) با علامت `#` و فیلتر تک‌کلیکی.

4. **جدول زمان‌بندی روز (Time Blocking)**:
   - تفکیک ساعات شبانه‌روز از صبح تا شب با برچسب‌های تخصصی کار عمیق، جلسه، ورزش و استراحت.

5. **رهگیری عادات و روتین‌ها (Habits & Streaks)**:
   - تفکیک روتین‌های صبح، بعد از ظهر و شب.
   - تاریخچه هفت‌روزه و شمارنده زنجیره پیوستگی (Streak).

6. **تایمر تمرکز پومودورو (Pomodoro Focus)**:
   - چرخه‌های ۲۵ دقیقه‌ای تمرکز و استراحت.
   - هشدار صوتی زنگ تبتی با Web Audio API بدون نیاز به فایل خارجی.
   - اتصال به وظیفه فعال و ثبت دقایق تمرکز روزانه.

7. **پشتیبان‌گیری و ذخیره‌سازی داده‌ها**:
   - ذخیره خودکار در `localStorage` مرورگر.
   - خروجی و بازیابی با فرمت استاندارد JSON.
   - پشتیبانی از حالت تاریک و روشن (Dark / Light Theme).
